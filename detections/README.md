## Detection Standard

Each detection should document:

- Objective and threat scenario
- Data source and required telemetry
- KQL detection logic
- MITRE ATT&CK mapping
- Severity and rationale
- Investigation pivots
- False-positive analysis
- Tuning guidance
- Validation / test cases
- Response guidance
