# D001 — Live Wazuh Alert Evidence

**Test date:** 2026-11-26  
**Detection:** D001 — Suspicious PowerShell execution  
**Custom rule:** 100500  
**Wazuh version:** 4.13.1  
**Source:** Windows Sysmon Event ID 1, collected through EventChannel  
**Result:** Live positive test passed

## Test action

A harmless PowerShell command was run on the Windows 11 lab endpoint with `-ExecutionPolicy Bypass`. The command printed a unique marker:

```text
SOC_D001_FINAL_20261126_202436
```

No external payload was downloaded or executed.

## Observed Wazuh alert

The resulting alert was found in:

```text
wazuh-alerts-4.x-2026.11.26
```

| Field | Observed value |
|---|---|
| Agent | Lab Windows endpoint (name redacted in this public record) |
| Decoder | `windows_eventchannel` |
| Location | `EventChannel` |
| Sysmon channel | `Microsoft-Windows-Sysmon/Operational` |
| Sysmon Event ID | `1` — Process Create |
| Process image | Windows PowerShell 5.1 executable |
| Parent image | Windows PowerShell 5.1 executable |
| Command-line indicator | `-ExecutionPolicy Bypass` |
| Test marker | `SOC_D001_FINAL_20261126_202436` |
| Custom Wazuh rule | `100500` |
| Alert level | `8` |
| Rule description | `SOC D001: Suspicious PowerShell execution pattern on [lab host]` |
| Rule group | `soc_d001`, `powershell` |
| ATT&CK technique | `T1059.001` — PowerShell |
| ATT&CK tactic | Execution |

The alert's `rule.id` was `100500`, and the rule matched the live Sysmon EventChannel event. This is the end-to-end positive detection evidence we were missing.

## Result

**D001 live positive validation: PASS.**

This confirms all of the following for this test:

1. The harmless PowerShell process was created.
2. Sysmon recorded the process as Event ID 1.
3. The Windows EventChannel event reached Wazuh.
4. Wazuh's EventChannel decoder processed the event.
5. The custom rule 100500 matched.
6. Wazuh indexed an alert in `wazuh-alerts-4.x-2026.11.26`.
