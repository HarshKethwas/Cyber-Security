# Threat Hunting

Behavior-focused hunts designed to identify suspicious activity that may not immediately trigger a high-confidence alert.

## Planned Hunting Areas

- PowerShell abuse
- Credential access
- Persistence
- Lateral movement
- Living-off-the-Land techniques
- Cloud identity anomalies
- Endpoint anomalies

Hunts will include hypotheses, telemetry requirements, KQL, investigation pivots, findings, and tuning opportunities.
